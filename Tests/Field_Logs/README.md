# Tests/Field_Logs/ — Per-entry landing pad

One file per field / experiment submission. Doctrine and submission
format live in `../Field_Logs.md` (index + contract).

**Filename:** `FL-YYYYMMDD-shortslug.md`  
If the path already exists, append `-2`, `-3`, or initials.

**Status (same pass as doctrine fold):**  
`Unreviewed` | `Reviewed — folded into [file]` | `Reviewed — no action`

**Non-goal:** AI session dumps stay in `Archive/Transcripts/`. This
folder is for field/run evidence only.

Run cards below are **ready to execute** when hardware/hosts exist.
Filling a card and pasting results into a new `FL-*.md` entry is the
intended path.
