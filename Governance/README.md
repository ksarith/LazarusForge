LazarusForgeV0 — Complete Governance Architecture Overview
The canonical README for the entire /governance directory. It explains the purpose, structure, and relationships of every governance layer, and it orients contributors to the Forge’s epistemic architecture. It’s written to be clear, authoritative, and aligned with the constitutional documents you’ve assembled.

---

1. Purpose of the Governance System
The governance system of LazarusForgeV0 ensures that the Forge evolves:

- safely,  
- coherently,  
- epistemically responsibly,  
- with full provenance,  
- under human oversight,  
- through structured verification,  
- with explicit uncertainty management.

Governance is not just rules — it is an epistemic institution.  
It governs how the Forge thinks, remembers, verifies, and matures.

---

2. Governance Hierarchy
The governance folder is organized into five layers, each with a distinct constitutional role.

`
/governance
    /constitutional
    /verification
    /modules
    /sandbox
    /legacy
`

Layer 1 — Constitutional Governance
Immutable principles that define the Forge’s identity.  
Files:  
- Core Governance  
- Computational Institutional Reasoning  
- Unknown Management  
- Verification & Safety Constraints  
- Provenance & Accountability  

Layer 2 — Verification & Safety
Formal mechanisms that ensure correctness, maturity, and risk control.  
Files:  
- Verification Gates  
- Safety Boundaries  
- Maturity Classification  
- Oversight Protocols  

Layer 3 — Operational Modules
Governed, verified, accountable operational logic.  
Files:  
- Operational Modules Framework  
- Agent Interaction  
- Revival Protocols  
- Reconstruction Rules  
- Contributor Workflow  
- Repository Integrity  
- Routing & Discovery  

Layer 4 — Experimental Sandbox
Exploration isolated from canonical architecture.  
Files:  
- Experimental Governance  
- /drafts for free‑form experimentation.

Layer 5 — Legacy
Archived history preserved for provenance.  
Files:  
- Archived Rules  
- Deprecated Modules  
- Retired Unknowns  

---

3. How the Layers Work Together
The governance system is intentionally hierarchical and interdependent.

Constitutional → Verification → Modules → Sandbox → Legacy

- Constitutional documents define what must always be true.  
- Verification documents define how truth is validated.  
- Modules define how the Forge operates.  
- Sandbox defines how the Forge explores.  
- Legacy defines how the Forge remembers.

This structure ensures clarity, stability, and epistemic rigor.
